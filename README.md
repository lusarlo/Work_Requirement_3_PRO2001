# Work Requirement 3 PRO2001

## Game Gallery
A responsive gallery with six of my favorite games, built with Vite (React + TypeScript) and React Bootstrap.
Each game is displayed in a reusable card with its portrait artwork, a short description, and a link to go to the official site of the game. 
The gallery uses one card per row on small screens, two per row on medium screens, and three per row on large screens.

## How to run the app

- Clone the repository using URL or download ZIP file: https://github.com/lusarlo/Work_Requirement_3_PRO2001

- Install dependecies on terminal: ```npm install```

- Start development server: ```npm run dev```

## Tools Used

- React
